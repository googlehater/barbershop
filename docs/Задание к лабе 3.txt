Лабораторная работа: Клиентский рендеринг и авторизация

Тема: Реализация проекта с применением SPA и авторизации
Предметная область: берите тему и страницы с прошлой лабораторной. Если по какой то причине взять ее не получится, пишите на почту

Цель лабораторной работы
 - Освоить клиентский рендеринг с помощью SPA
 - Научиться использовать ORM
 - Использовать архитектуру с разделением на клиент и сервер
 - Научиться использовать авторизацию

Требования к проекту
 - Должно быть явное разделение на фронтенд и бэкенд, у каждого свой контейнер
 - Использование SPA фрейморвка на клиентской стороне
 - Развертывание БД через Docker Compose
 - Все запросы в БД происходят строго через ORM
 - Для генерации схемы БД используются миграции
 - Аутентификация через JWT или сессии
 - Пароли хэшируются через bcrypt или аналогичные функции с солью
 - Контент страницы зависит от прав пользователя. Можно предоставлять данные которые ему принадлежат или давать доступ к разным страницам в зависимости от прав. Самое банальное - админская панель
 - Должно быть минимум 2 эндпоинта(помимо установки токена и регистрации), функционал которых требует авторизации. Если будете делать админскую панель, можете на нее впихнуть статистику и графики(запросы на данные к ним через авторизацию)
 - Взаимодействие бэкенда и фронтенда через api, api соответствует правилам REST
